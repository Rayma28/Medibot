# 🩺 MediBot: Medical Diagnosis Chatbot

This project is an AI-powered chatbot that provides basic medical diagnostics based on user input. It utilizes a trained machine learning model to predict possible diseases from symptoms described by the user, offering helpful insights and advice on what to do next.

## 🚀 Features
- Interactive chatbot interface for symptom-based conversation
- Predicts possible diseases based on user input
- Trained on a comprehensive dataset of medical symptoms and conditions
- Provides basic preventive advice and recommendations
- Simple and intuitive UI for ease of use

## ⚙️ Technologies Used
- Python (Flask)
- Natural Language Processing (NLP)
- Machine Learning (Scikit-learn, Pandas)
- HTML/CSS/JavaScript (for front-end)

## 📦 Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/medical-diagnosis-chatbot.git
   cd medical-diagnosis-chatbot
   ```
2. Install dependencies:
   ```bash
   pip install dependencies
   ```
3. Run the Flask app:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to:
   ```
   http://127.0.0.1:5000/
   ```
